# 验证记录

整理日期：2026-11-07。本文区分原项目成果与本次软件检查。

## 原项目实物成果

依据作者说明及提供的视频材料，项目完成了平面试件上的视觉定位、机械臂轨迹执行和实际喷漆，并演示了独立蓝牙遥控喷枪开关。底盘在喷涂阶段固定。

资料没有提供定位误差、面积误差、涂层厚度、均匀性、成功率或与人工喷漆效率的量化对照，因此不添加相关数值。管廊现场与管道曲面姿态跟随未列为已验证能力。

## 复现检查

在仓库根目录安装所需软件依赖后执行：

```powershell
python -m unittest discover -s tests -v
python -m compileall -q software tools tests run.py
python tools/check_gui.py v1
python tools/check_gui.py v2
python tools/check_project.py
```

Qt 两个版本的检查分别使用独立进程。`tools/check_gui.py` 会更新整理版离线截图，且不会建立物理设备连接。
