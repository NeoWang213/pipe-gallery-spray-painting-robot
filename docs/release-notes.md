# 项目作品集与原始演示材料

本项目集成麦克纳姆轮底盘、UFACTORY xArm6、独立喷漆系统和 Python 上位机，面向管廊内管道外壁维护。

个人主要工作包括喷漆系统及嵌入式电控集成、整机控制平台开发、视觉选区和喷涂轨迹规划。已在平面试件上完成实际喷漆验证，底盘在作业中固定，喷枪由独立遥控开关控制。

源码保留 v1.0 和 v2.0 历史版本，并提供整理后的离线入口、配置及异常处理。v1.0 已申请软著，原用户手册随仓库提供。整理版的检查为离线软件验证，尚未进行新增实物复测。

附件对应客户端演示、定位演示、喷漆定位验证及蓝牙控制喷枪。GIF 为视频抽帧预览，完整过程以原视频为准。
